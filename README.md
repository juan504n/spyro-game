# Gloaming Vale — a PS1-style Spyro DLC realm in three.js

*Lantern Keepers Pack · one new realm · 700 gems · 5 beacons · no asset files — it is all code.*

A fan-made, unofficial tribute to the PlayStation-era Spyro games. It is a complete, playable platformer level
built with [three.js](https://threejs.org/) and rendered through a custom pipeline that reproduces the look of the
original console: 320×240 output, wobbling vertices, affine-warped textures, 15-bit colour with the PS1 dither
matrix, per-vertex lighting and fog, and 30 fps if you want it.

**Two looks.** The default is *smooth*, like an emulator's enhanced mode: 480 lines, smoothly filtered textures, 4× MSAA,
no dither and no vertex wobble. **Options → LOOK → PS1 AUTHENTIC** switches to the strict 240p artefacts described below
(point-sampled textures, 15-bit dither, wobbling vertices, affine texture warp); every ingredient can also be toggled on its own.
**Options → COLORS** is a separate grade: *classic* is the moody dusk palette, *vivid* (default) lifts the mid-tones and enriches
the colours, *extra vivid* goes further towards the bright, saturated look of console footage. It is applied to the 3D scene only (the HUD keeps its colours).

Everything you see and hear — terrain, 60+ textures, sprites, the bitmap font, every model, the music and the
sound effects — is **generated by code at start-up**. The game loads no image, model or audio files.

## Play it

* **Instantly:** open [`docs/index.html`](docs/index.html) in a desktop browser (it is one self-contained file;
  also works from GitHub Pages if you serve `/docs`).
* **From source:**

  ```bash
  npm install
  npm run dev          # http://127.0.0.1:5173
  npm run build:single # rebuilds docs/index.html (single file, three.js inlined)
  ```

Needs WebGL2. Click the game once to capture the mouse and start the audio. On phones and tablets use landscape: touch
controls appear automatically (the display defaults to widescreen there; **Options → Display** switches back to the 4:3 frame).

## The realm

Gloaming Vale is a valley that has been stuck in twilight ever since the Snuffers stole the sunrise. Elder Wick, the last
Lantern Keeper, asks you to relight the five Beacon Lanterns. Each one you ignite pushes the sky a step towards dawn —
the whole valley is lit twice (dusk and daybreak) and the world cross-fades between the two as you progress.

| # | Beacon | Where | What it asks of you |
| - | --- | --- | --- |
| I | Hearth | Hearth Village, spawn | Tutorial: jump, glide, fire. |
| II | Isle | Mirrormere lake | Hop the stepping-stone reef to the shrine island. |
| III | Mill | Windmill hill (spiral road) | Light the three braziers to raise the portcullis. |
| IV | Sky | Floating isles | Bounce off the mesa mushroom, then glide island to island. |
| V | Dawn | Observatory at the top of the spiral mountain | The Dawn Gate only opens once four beacons burn. |

* **Snuffers** come in three kinds: plain ones (fire or charge), *bell* Snuffers (armoured — fire bounces off, charge them)
  and *thorn* Snuffers (spiked — don't ram them, burn them).
* **Sparx** the dragonfly is your health bar: blue → green → yellow → gone. Bunnies you scorch become healing
  butterflies.
* **Gems** are worth 1 / 2 / 5 / 10 / 25 (red, green, blue, gold, purple): cut stones whose facets flash as they spin. Vases, chests, cracked walls and enemies drop
  them, plus hand-placed trails and a few well-hidden treasures. Total: **700**.
* Ending the level shows a results screen (three stars) and drops you back into free roam.

## The hero

Spyro is built in code like everything else (`src/game/models/creatures/spyro.js`): about 1.5 k vertex-coloured, Gouraud-lit
triangles on a pivot rig (no skinning). The design follows the classic PS1 look — a big blocky head with large eyes and a short
muzzle, long ringed horns, a gold crest, maroon wings with golden finger bones that stand up like sails (and spread flat for the
glide), a thick upright neck with a banded gold chest, stubby paws with pale claws and a thin tail with a small orange tip.
It is drawn by eye as original geometry: no ripped model, texture or animation data is used.

## How the PS1 look is made

| Hardware trait | How it is reproduced here |
| --- | --- |
| 320×240 frame buffer | Scene renders into a 320×240 target (optional wide / 480-line modes), integer-scaled or "sharp bilinear" to the window. The HUD is drawn at that same internal resolution. |
| Integer vertex coordinates ("jitter") | Clip-space vertices are snapped to whole pixels in the vertex shader (`ps1Snap`). |
| No perspective correction | UVs are interpolated affinely (`uv * w` trick), so big near polygons swim exactly like the original. Toggle in options. |
| Gouraud shading only | All lighting is baked into vertex colours. Static geometry stores irradiance for **both** moonlit-gloaming and daybreak (heightfield shadow ray-march + prop shadow stamps) and the shader blends them by the current time of day. Dynamic models use one directional + ambient term evaluated per vertex. |
| `texture × colour × 2` blending | 0.5 vertex colour is neutral, values above brighten — the GPU's modulate mode. |
| Per-vertex fog | Fog is computed in the vertex shader and interpolated, so it bands across large triangles. |
| 15-bit colour + ordered dither | Final pass quantises to 5 bits per channel after adding the PS1 4×4 dither matrix (offsets −4…+3). |
| Nearest filtering, no mipmaps | Textures are tiny (16–64 px), palette-limited, point sampled. |
| 1-bit / 50 % / additive transparency | Cut-outs are alpha-tested; water and glass use the 50 % blend; glows are additive. |
| 30 fps | Optional lock: simulation keeps running while every second frame is presented. |

Honest caveat: the *rendering artefacts* are faithful, the *budgets* are not — the terrain is a ~52 k-triangle heightfield,
far more than a PS1 could push. A frame submits roughly 200 k triangles and 250–300 draw calls (the static world meshes are
not frustum-culled), which integrated graphics and recent phones handle at 320×240; **Options → 30 FPS lock** helps older devices.

## Repository tour

```
src/engine/          renderer + PS1 pipeline (shaders, materials, gfx, builder, lighting)
  textures/          procedural pixel-art toolkit: 62 world textures, sprites, bitmap font, UI atlas
  audio/             procedural PS1-SPU-style synth: music (dusk + daybreak variants), ambience, stingers, ~60 sound assets
                     (the gem chimes are the exception: clean 48 kHz stereo, see sfx-gems.js)
src/game/
  level.js           the design source of truth: landmarks, roads, hills, beacon order
  terrain*.js        analytic heightfield, road/river carving, per-triangle texturing, water
  props/  models/    procedural scenery, architecture, hero, creatures and interactive objects
  levelgen/          deterministic placement of props, enemies, gems, hints
  player.js camera.js collision.js   kinematic controller, chase camera, heightfield + collider world
  systems/           gems, Sparx, beacons, enemies, critters, NPC, objects, ambience
  app.js hud.js menu.js cinematics.js   title → intro → play → finale → results, HUD, options
tools/               QA + dev tooling (see below)
docs/index.html      the built single-file game
```

### Tooling

```bash
npm run qa                    # prop lint + reachability bot + full story playthrough (needs the dev server running)
node tools/bot.mjs            # headless reachability bot: drives the real controller along every road/route
node tools/playthrough.mjs    # every beacon, the brazier puzzle, sky-isle glide chain, Dawn Gate, finale
node tools/monkey.mjs [runs] [secs]   # random-input soak test: exceptions, NaNs, players escaping the world
node tools/terrain-map.mjs    # top-down map of the realm with slopes and paths -> terrain-map.png
node tools/prop-lint.mjs      # builds every prop, fails on NaN / degenerate geometry
node tools/shot.mjs / play.mjs / probe.mjs   # Playwright screenshots, scripted play-throughs, state probes
node tools/model-sheet.mjs out.png --only spyro --poses idle,run,glide --views side   # contact sheets of an actor from any angle / pose
node tools/audio-render.mjs   # renders every sound to WAV and prints diagnostics
node tools/build-single.mjs   # esbuild -> one HTML file
```

The bot scripts need the dev server (`GV_HMR=0 npm run dev`) and Playwright with Chromium.

Dev-only scenes (not in the single-file build) are reachable through `?test=`: `props` (scenery gallery), `models`
(hero, enemies and objects with their test poses), `world` (the realm with a scripted camera), `pipeline-test` (every PS1
effect on a test scene) and `play` (bare world plus controller, for tuning movement). Example: `http://127.0.0.1:5173/?test=models&only=spyro&pose=run`.
