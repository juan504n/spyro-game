open-spyro in the browser

open-spyro is a byte-for-byte decompilation of Spyro the Dragon (PS1, NTSC-U, SCUS_942.28): its build is a PlayStation disc. This page boots that disc in a PlayStation emulator compiled to WebAssembly (EmulatorJS, with the PCSX-ReARMed core, or Beetle PSX for HD), right here in the tab. The disc never leaves your computer; nothing is uploaded.

2 · Graphics

About frame rate: Spyro the Dragon itself runs at up to 30 frames a second, and dips below that in busy scenes on a real PlayStation too. The overclock lets the game keep its 30 when the screen is busy (if it misbehaves, turn it off). Going past 30 would mean changing the game's own code; no emulator setting does it.

BIOS: none

The PlayStation's own startup chip, dumped from a console you own (512 KB, e.g. SCPH1001.BIN or SCPH5501.BIN). Required for HD. In Standard it is optional and adds the PlayStation boot animation. It is kept in this browser, never uploaded.

Where the disc comes from

  1. Rip your own Spyro the Dragon (NTSC-U) disc to .bin/.cue. It boots here as is.
  2. Or rebuild it from the decompilation. With Docker and uv installed, put that rip in open-spyro's iso/ folder and run: 
    git clone https://github.com/theMagicalKarp/open-spyro && cd open-spyro
make setup setup-iso   # matching toolchain + disc tools
make extract split     # unpack your disc, disassemble it
make check iso         # build, verify byte-identical, repack
    then drop build/SpyrotheDragon.bin (or the .bin and .cue together) on this page. Change a function in src/, rebuild, drop it again: the line under the file name says whether the executable is still byte-identical to retail.

No game data comes with this page or with open-spyro. If a large .bin runs the tab out of memory, convert it with chdman createcd -i SpyrotheDragon.cue -o spyro.chd: about half the size, and it boots the same in HD.

A gamepad works as a DualShock. Every key can be changed under the controls icon in the player's bottom bar, which also has save states and full screen. On phones and tablets an on-screen pad appears. Memory card saves are kept in this browser.
